# INSTANCES.md — 实例总表（论文主论证数据）

> 核心观点：**在 OI 黑盒反馈下，大模型修复算法代码的能力由错误深度决定：
> 浅伤（实现层）可迭代修复至满分；深伤（算法层）不可修复，迭代止步平台期。**
> 判定标准：错误深度按修复所改动的层面划分——仅动边界/精度/输出/局部逻辑 = 浅伤；
> 始终无法脱离原算法框架或分数长期低于半数 = 深伤。逐例可复核（roundN.cpp 均在库）。
