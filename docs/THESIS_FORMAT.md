# THESIS_FORMAT.md — 论文格式规范（从模板提取）

> 模板：2025年秋《算法设计与分析实验》实验报告-班级-学号-姓名（模板）.docx
> 学校：华中科技大学 网络空间安全学院

## 页面设置
- A4（7560310 × 10692130 EMU ≈ 21cm × 29.7cm）
- 页边距：左右各 685800 EMU ≈ 1.9cm，上下各 914400 EMU ≈ 2.54cm

## 前四页（不修改）
- 封面页：华中科技大学 / 网络空间安全学院 / 本科《算法设计与分析实验》报告 / 姓名 / 班级 / 学号 / 联系方式 / 分数 / 评分人 / 日期
- 报告要求页：3 条纪律
- 报告评分表

## 正文章节结构（Heading 1 为章标题）
每章按以下结构组织（Heading 1 + Heading 2）：

```
第X章 算法名称（Heading 1，宋体小4号加粗）
  X.1 问题描述（Heading 2）
      - 题目描述 / 输入格式 / 输出格式 / 题目来源
  X.2 算法设计
  X.3 复杂度分析（时间 + 空间）
  X.4 实验验证与结果分析
  X.5 代码实现
```

## 字体与格式要求

| 元素 | 格式 |
|------|------|
| **正文** | 宋体小4号，行间距固定1.5倍行距，字符间距标准 |
| **章标题（H1）** | 宋体小4号**加粗** |
| **节标题（H2）** | 宋体小4号加粗 |
| **字母/数字** | Times New Roman 小4号 |
| **表标题** | 位于表格**上方**，黑体小4号（字母数字 Times New Roman 小4号） |
| **表内容** | 宋体5号（字母数字 Times New Roman 5号） |
| **参考文献** | 宋体小4号 |
| **代码** | 不可大段粘贴，应配合文字说明和流程图/伪代码 |

## 其他规则
- 章与章之间插入分页符
- 报告不可只粘贴大段代码，应文字与图、表结合
- 需要说明流程时用流程图或伪代码
- 图表需要编号和标题

## 最后章节
```
实验总结（Heading 1）
  4.1 遇到问题及解决方法
  4.2 感想
  4.3 意见或建议
附录 参考文献（Heading 1）
```
